COMPLETE CONNECTIONS SUMMARY:
===============================

POWER CONNECTIONS:
─────────────────
U1 Pin 8  ──→  +5V
U2 Pin 8  ──→  +5V
U1 Pin 4  ──→  GND (Common)
U2 Pin 4  ──→  GND (Common)

STAGE 1 - VOLTAGE FOLLOWER (U1):
─────────────────────────────────
U1 Pin 3 (Non-Inv)  ←── R1 (100k) ←── Signal Input
R1 junction         ←── R2 (100k) ←── GND
U1 Pin 1 (Output)   ←→ U1 Pin 2 (Inv)  [Feedback for unity gain]
U1 Pin 1 (Output)   ──→ U2 Pin 5 (Non-Inv) [Signal path to Stage 2]

STAGE 2 - PRECISION RECTIFIER (U2):
────────────────────────────────────
U2 Pin 5 (Non-Inv)  ←── U1 Pin 1 Output
U2 Pin 7 (Output)   ──→ D1 Anode (long leg)
D1 Cathode (short)  ←→ U2 Pin 6 (Inv) + V_PEAK junction

STAGE 3 - PEAK-HOLD (RC Network):
──────────────────────────────────
V_PEAK junction     ←── D1 Cathode
V_PEAK junction     ─→ C1 (+) positive terminal
V_PEAK junction     ─→ R3 one end
C1 (-) negative     ──→ GND
R3 other end        ──→ GND

MEASUREMENT POINTS:
───────────────────
Oscilloscope Channel 1 (Input):   Signal after R1 or U1 output
Oscilloscope Channel 2 (Output):  V_PEAK node (peak-hold output)

SIGNAL FLOW DIAGRAM:
====================

Input Signal (0.45-0.55V)
    ↓
[R1=100k Resistor]
    ↓
[Voltage Divider with R2]
    ↓
[U1 - Voltage Follower Buffer]  ← Buffers weak input, prevents loading
    ↓
[Buffered Signal - 0.45-0.55V]
    ↓
[U2 - Precision Rectifier]  ← Compares with stored peak
    ↓ (if new peak is higher)
[D1 Diode Conducts]  ← Forward biased
    ↓
[Charges C1 to new peak value]  ← Fast charging (milliseconds)
    ↓
[Stores peak in C1]
    ↓ (if signal drops)
[D1 Blocks]  ← Reverse biased, acts as open switch
    ↓
[C1 Holds voltage]
    ↓ (slowly discharges)
[R3 Discharge Path]  ← Slow discharge (seconds)
    ↓
[V_PEAK Output]  ← Peak voltage held for measurement


TEST POINTS FOR MULTIMETER:
===========================

Point 1: Between R1 and R2 junction
         Expected: ~2.5V DC (bias voltage)

Point 2: U1 Output (Pin 1)
         Expected: Signal voltage ~0.45-0.55V

Point 3: V_PEAK junction (before R3/C1)
         Expected: Peak value ~0.5V (slowly decaying)

Point 4: Across capacitor C1
         Expected: Peak voltage with slow decay

All measurements should be taken with oscilloscope on DC mode
or multimeter set to DC voltage.


NOTES:
======
- All connections must be secure and free of cross-contamination
- Use color-coded wires: Red for +5V, Black for GND, Others for signals
- Measure all voltages relative to common ground
- Signal generator ground must be connected to circuit ground
- Oscilloscope grounds must all connect to circuit ground
